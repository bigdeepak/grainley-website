# Grainley Foods website

The public website for Grainley Foods (grainleyfoods.com). Every product links to its Amazon.in listing.

- `index.html`, `shop.html`, `products/` — pages
- `assets/` — styles, scripts, pouch mockups, combo shots and Amazon listing images
- Hosted free on GitHub Pages; `.github/workflows/deploy.yml` publishes every change to `main`.
